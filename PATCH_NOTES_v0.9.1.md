# DWM v0.9.1

- Corrected validation semantics: validation is an Operator edit freeze, not a visibility lock.
- Operators can always open/view validated reports within their assigned project.
- Operators can always view/download PDF for validated reports.
- Operators cannot edit/recalculate validated reports.
- Supervisor/Admin can always view/edit validated reports.
- Re-open enables Operator editing again.
- Copy/Create Next remains available so a new crew can start the next report from the validated handover report.
